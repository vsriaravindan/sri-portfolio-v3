# BankChain — Decentralized Bank (DeFi Protocol) Implementation Plan

> **For Hermes:** Use `delegate_task` (parallel subagents) to implement task groups. Each group is self-contained. Execute contracts first, then backend + frontend in parallel, then AI agent.
>
> **Critical rule:** All Solidity math uses `ray` (1e27) scaling for interest rate accumulation. Never use `block.timestamp` for critical economic decisions without time-weighting. All lending functions use OpenZeppelin `ReentrancyGuard`.

**Goal:** Build a complete, deployable Decentralized Bank with custom ERC-20 token, yield-bearing savings vault, over-collateralized lending pool, Web3 wallet integration, and Hermes AI agent with DeepSeek for natural-language banking operations.

**Architecture:** Monorepo with 4 packages — Hardhat (Solidity contracts with OpenZeppelin), Express/Prisma backend (WebSocket indexer + REST API), Next.js 14 frontend (wagmi/viem wallet connection), and Hermes plugin (DeepSeek tool agent). Contracts use audited OpenZeppelin patterns exclusively. Interest accrual uses the cumulative-index (ray math) pattern.

**Tech Stack:**
- **Chain:** Polygon Amoy testnet (EVM-compatible)
- **Contracts:** Solidity ^0.8.20, OpenZeppelin v5.x, Hardhat
- **Backend:** Node.js + Express, Prisma ORM + PostgreSQL, ethers.js v6
- **Frontend:** Next.js 14 App Router, wagmi v2, viem v2, Tailwind CSS
- **AI:** Hermes custom tool plugin, DeepSeek API for NL→function mapping
- **Testing:** Hardhat test (chai + ethers), TypeScript

## Logical Flow & Edge Case Analysis

### Token (BankToken)
| Scenario | Expected Behavior |
|----------|------------------|
| Non-owner tries mint | Revert (Ownable) |
| Mint when paused | Revert (Pausable) |
| Burn exceeds balance | Revert (ERC20) |
| Transfer to zero address | Revert (ERC20) |
| Owner renounces ownership | Contract becomes immutable (no further mint/burn) |

### Savings Vault (ERC4626)
| Scenario | Expected Behavior |
|----------|------------------|
| Deposit 0 assets | Revert (check `assets > 0`) |
| Withdraw more than balance | Revert (ERC4626 standard) |
| First depositor front-run | Mitigated by `_convertToShares` using `supply == 0` → assets directly |
| Vault accrues yield | `totalAssets()` returns token balance (yield comes from lending pool interest) |
| Paused vault | deposit/withdraw revert (Pausable inherited) |

### Lending Pool (Critical — High Risk)
| Scenario | Expected Behavior |
|----------|------------------|
| Borrow exceeds LTV | Revert (`_checkHealthFactor`) |
| Repay more than debt | Revert (repay math capped at debt) |
| Interest accrual over time | `borrowIndex` updates per second: `newIndex = oldIndex * (1 + ratePerSecond * elapsed)` |
| Liquidation of healthy position | Revert (health factor > 1) |
| Liquidation of undercollateralized | Liquidator repays debt → receives collateral + bonus |
| Withdraw collateral while borrowing | Revert (would make position unhealthy) |
| Flash loan attack surface | ReentrancyGuard on all state-mutating functions |

### Interest Rate Model
- `ratePerSecond` = annual rate / 365 days / 86400 seconds
- All rates in `ray` (1e27 decimal)
- `borrowIndex` accumulates: `index(t) = index(t-1) * (1 + ratePerSecond * elapsed)`
- User debt = `borrowAmount * currentIndex / lastUpdateIndex`

### Liquidation Math
- Health Factor = `collateralValue * 100 / (borrowValue * liquidationThreshold)` — must be > 100
- When HF < 100: liquidator repays up to 50% of debt
- Liquidator receives `repaidAmount * (100 + liquidationBonus) / 100` worth of collateral
- Liquidation bonus: 5-10% (configurable via Treasury)

#### Task A3: SavingsVault.sol — ERC4626 Yield Vault

**Objective:** Standard yield vault where users deposit BCK and receive yield-bearing shares

**File:** `BankChain/contracts/vault/SavingsVault.sol`

**Key features:**
- Inherits: ERC4626, Ownable2Step, ReentrancyGuard, Pausable
- Constructor: `asset (BankToken), vaultName, vaultSymbol, Treasury`
- Yield comes from lending the deposited tokens to the LendingPool
- `deposit(assets, receiver)` — public, pausable
- `withdraw(assets, receiver, owner)` — public, pausable
- Override `totalAssets()` to return `asset.balanceOf(address(this))`
- Vault Admin (owner) can set performance fee (capped at 20%)
- Fee taken on each withdraw: `fee = earnedAssets * feeBasisPoints / 10000`

**Edge cases:**
- Inflate attack mitigation: First depositor slippage — OpenZeppelin ERC4626 v5 mitigates by using `_checkZeroAndConvert` in `_convertToShares`
- MAX_DEPOSIT returns type(uint256).max (no cap)
- Deposit during paused state → revert

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import "@openzeppelin/contracts/token/ERC20/extensions/ERC4626.sol";
import "@openzeppelin/contracts/access/Ownable2Step.sol";
import "@openzeppelin/contracts/utils/ReentrancyGuard.sol";
import "@openzeppelin/contracts/token/ERC20/extensions/ERC20Pausable.sol";
import "@openzeppelin/contracts/utils/Pausable.sol";

error FeeTooHigh();
error ZeroAmount();

contract SavingsVault is ERC4626, Ownable2Step, ReentrancyGuard, Pausable {
    using SafeERC20 for IERC20;

    uint256 public constant MAX_FEE = 2000; // 20%
    uint256 public feeBasisPoints = 500; // 5% default
    address public treasury;

    event FeeUpdated(uint256 oldFee, uint256 newFee);
    event TreasuryUpdated(address indexed oldTreasury, address indexed newTreasury);

    constructor(
        IERC20 _asset,
        string memory _name,
        string memory _symbol,
        address _treasury
    ) ERC4626(_asset) ERC20(_name, _symbol) Ownable2Step(msg.sender) {
        treasury = _treasury;
    }

    modifier nonZero(uint256 amount) { if (amount == 0) revert ZeroAmount(); _; }

    function setFee(uint256 _fee) external onlyOwner {
        if (_fee > MAX_FEE) revert FeeTooHigh();
        emit FeeUpdated(feeBasisPoints, _fee);
        feeBasisPoints = _fee;
    }

    function setTreasury(address _treasury) external onlyOwner {
        emit TreasuryUpdated(treasury, _treasury);
        treasury = _treasury;
    }

    function totalAssets() public view override returns (uint256) {
        return _asset.balanceOf(address(this));
    }

    function deposit(uint256 assets, address receiver)
        public override nonReentrant whenNotPaused nonZero(assets) returns (uint256) {
        return super.deposit(assets, receiver);
    }

    function mint(uint256 shares, address receiver)
        public override nonReentrant whenNotPaused returns (uint256) {
        return super.mint(shares, receiver);
    }

    function withdraw(uint256 assets, address receiver, address owner)
        public override nonReentrant returns (uint256) {
        uint256 shares = super.withdraw(assets, receiver, owner);
        _applyFee(owner, assets);
        return shares;
    }

    function redeem(uint256 shares, address receiver, address owner)
        public override nonReentrant returns (uint256) {
        uint256 assets = super.redeem(shares, receiver, owner);
        _applyFee(owner, assets);
        return assets;
    }

    function _applyFee(address _user, uint256 _assets) internal {
        if (feeBasisPoints > 0 && treasury != address(0)) {
            uint256 totalBal = totalAssets() + _assets; // before-withdrawal balance
            uint256 userBal = balanceOf(_user);
            if (userBal > 0 && totalBal > 0) {
                uint256 earned = (totalBal * userBal / totalSupply()) - _assets;
                if (earned > 0) {
                    uint256 fee = earned * feeBasisPoints / 10000;
                    if (fee > 0) {
                        SafeERC20.safeTransfer(_asset, treasury, fee);
                    }
                }
            }
        }
    }

    function pause() external onlyOwner { _pause(); }
    function unpause() external onlyOwner { _unpause(); }
}
```

#### Task A4: LendingPool.sol — Over-Collateralized Lending

**Objective:** The core lending protocol. Users deposit BCK as collateral, borrow BCK up to LTV, repay with interest.

**File:** `BankChain/contracts/lending/LendingPool.sol`

**CRITICAL MATH:**

- `PRECISION = 1e27` (ray)
- `_updateIndex()`: every state-mutating call refreshes `borrowIndex`
- `newIndex = borrowIndex * (RAY + ratePerSecond * blockDelta) / RAY`
- `_calculateDebt(user)`: `user.borrowAmount * borrowIndex / user.borrowIndex`
- Liquidation: Health Factor = `collateralValue * 10000 / (debtValue * liquidationThreshold)`

**Structs:**
```solidity
struct UserPosition {
    uint256 collateral;        // BCK deposited as collateral
    uint256 borrowAmount;      // Total BCK borrowed (in borrowIndex terms)
    uint256 borrowIndex;       // Index at last borrow/repay
    uint256 lastUpdateTime;
}

struct PoolState {
    uint256 totalCollateral;   // Total BCK locked as collateral
    uint256 totalBorrows;      // Total BCK borrowed (in current index terms)
    uint256 availableLiquidity; // BCK available for withdrawals
    uint256 borrowIndex;       // Current accumulated borrow index
    uint256 lastUpdateTime;
}
```

**Rate Model:**
- baseRate = 2% APR at 0% utilization
- slope1 = 7% APR up to kink (80% utilization)
- slope2 = 200% APR above kink (penalty zone)

**Configuration (settable via Treasury timelock):**
```solidity
uint256 public liquidationThreshold = 8000;  // 80% (10000 = 100%)
uint256 public liquidationBonus = 500;        // 5%
uint256 public constant RAY = 1e27;
```

**Functions:**
- `depositCollateral(uint256 amount)` — transfer BCK from user, increase collateral
- `withdrawCollateral(uint256 amount)` — only if health factor > 1 after withdrawal
- `borrow(uint256 amount)` — only if health factor > 1 after borrow
- `repay(uint256 amount)` — repay debt, repay max if amount > debt
- `liquidate(address user)` — anyone can liquidate if HF < 1
- `getAccountInfo(address user)` — view: collateral, debt, health factor, max borrow

**Edge cases in code:**
- User borrows 0 → revert
- User repays more than debt → capped to debt amount
- HF == 1 at liquidation boundary → use `<` not `<=` to avoid edge
- First borrow sets user's borrowIndex
- Utilization = 0 when totalBorrows == 0 (avoid div by zero)

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import "@openzeppelin/contracts/access/Ownable2Step.sol";
import "@openzeppelin/contracts/utils/ReentrancyGuard.sol";
import "@openzeppelin/contracts/token/ERC20/utils/SafeERC20.sol";
import "@openzeppelin/contracts/token/ERC20/IERC20.sol";
import "@openzeppelin/contracts/utils/Pausable.sol";

error InsufficientCollateral();
error HealthFactorTooLow();
error CannotBorrowZero();
error InsufficientLiquidity();
error LiquidationNotNeeded();

contract LendingPool is Ownable2Step, ReentrancyGuard, Pausable {
    using SafeERC20 for IERC20;

    uint256 public constant RAY = 1e27;
    uint256 public constant PRECISION = 10000; // basis points
    uint256 public constant SECONDS_PER_YEAR = 365 days;

    // Rate params (all in ray)
    uint256 public constant BASE_RATE = 0.02e27;      // 2%
    uint256 public constant SLOPE1 = 0.07e27;          // 7%
    uint256 public constant SLOPE2 = 2.00e27;          // 200%
    uint256 public constant OPTIMAL_UTILIZATION = 0.80e27; // 80%

    // LTV params (basis points)
    uint256 public liquidationThreshold = 8000; // 80%
    uint256 public liquidationBonus = 500;      // 5%

    IERC20 public immutable bankToken;
    address public treasury;

    struct UserPosition {
        uint256 collateral;
        uint256 borrowAmount;   // Scaled to borrowIndex at borrow time
        uint256 borrowIndex;    // Index snapshot at last borrow/repay
    }

    struct PoolState {
        uint256 totalCollateral;
        uint256 totalBorrows;
        uint256 borrowIndex;
        uint256 lastUpdateTime;
    }

    PoolState public state;
    mapping(address => UserPosition) public users;

    event CollateralDeposited(address indexed user, uint256 amount);
    event CollateralWithdrawn(address indexed user, uint256 amount);
    event Borrowed(address indexed user, uint256 amount);
    event Repaid(address indexed user, uint256 amount);
    event Liquidated(address indexed liquidator, address indexed user, uint256 repaid, uint256 seized);

    constructor(IERC20 _bankToken, address _treasury) Ownable2Step(msg.sender) {
        bankToken = _bankToken;
        treasury = _treasury;
        state.borrowIndex = RAY;
        state.lastUpdateTime = block.timestamp;
    }

    modifier updateIndex() {
        _accrueInterest();
        _;
    }

    function _accrueInterest() internal {
        uint256 elapsed = block.timestamp - state.lastUpdateTime;
        if (elapsed > 0) {
            uint256 utilization = _getUtilization();
            uint256 ratePerSecond = _calcRate(utilization);
            uint256 delta = (ratePerSecond * elapsed) / SECONDS_PER_YEAR;
            state.borrowIndex = (state.borrowIndex * (RAY + delta)) / RAY;
            state.lastUpdateTime = block.timestamp;
        }
    }

    function _getUtilization() internal view returns (uint256) {
        uint256 total = state.totalBorrows;
        if (total == 0) return 0;
        uint256 liquidity = bankToken.balanceOf(address(this));
        uint256 totalPool = total + liquidity;
        if (totalPool == 0) return 0;
        return (total * RAY) / totalPool;
    }

    function _calcRate(uint256 utilization) internal pure returns (uint256) {
        if (utilization < OPTIMAL_UTILIZATION) {
            return BASE_RATE + (SLOPE1 * utilization) / OPTIMAL_UTILIZATION;
        } else {
            uint256 excess = utilization - OPTIMAL_UTILIZATION;
            uint256 remaining = RAY - OPTIMAL_UTILIZATION;
            return BASE_RATE + SLOPE1 + (SLOPE2 * excess) / remaining;
        }
    }

    function _getCurrentDebt(address user) internal view returns (uint256) {
        UserPosition memory u = users[user];
        if (u.borrowAmount == 0) return 0;
        return (u.borrowAmount * state.borrowIndex) / u.borrowIndex;
    }

    function _getHealthFactor(address user) internal view returns (uint256) {
        UserPosition memory u = users[user];
        if (u.collateral == 0) return 0;
        uint256 debt = _getCurrentDebt(user);
        if (debt == 0) return type(uint256).max;
        return (u.collateral * liquidationThreshold * 1e18) / (debt * PRECISION);
    }

    function depositCollateral(uint256 amount) external nonReentrant whenNotPaused updateIndex {
        if (amount == 0) revert CannotBorrowZero();
        bankToken.safeTransferFrom(msg.sender, address(this), amount);
        users[msg.sender].collateral += amount;
        state.totalCollateral += amount;
        emit CollateralDeposited(msg.sender, amount);
    }

    function withdrawCollateral(uint256 amount) external nonReentrant whenNotPaused updateIndex {
        UserPosition storage user = users[msg.sender];
        if (amount > user.collateral) revert InsufficientCollateral();
        user.collateral -= amount;
        state.totalCollateral -= amount;
        if (_getHealthFactor(msg.sender) < 1e18) {
            user.collateral += amount;
            state.totalCollateral += amount;
            revert HealthFactorTooLow();
        }
        bankToken.safeTransfer(msg.sender, amount);
        emit CollateralWithdrawn(msg.sender, amount);
    }

    function borrow(uint256 amount) external nonReentrant whenNotPaused updateIndex {
        if (amount == 0) revert CannotBorrowZero();
        UserPosition storage user = users[msg.sender];
        uint256 currentDebt = _getCurrentDebt(msg.sender);
        uint256 newTotalDebt = currentDebt + amount;
        uint256 hf = _getHealthFactor(msg.sender);
        if (hf < 1e18) revert HealthFactorTooLow();
        if (amount > bankToken.balanceOf(address(this))) revert InsufficientLiquidity();

        user.borrowAmount = (newTotalDebt * user.borrowIndex) / state.borrowIndex;
        if (user.borrowIndex == 0) user.borrowIndex = state.borrowIndex;
        state.totalBorrows += amount;
        bankToken.safeTransfer(msg.sender, amount);
        emit Borrowed(msg.sender, amount);
    }

    function repay(uint256 amount) external nonReentrant updateIndex {
        UserPosition storage user = users[msg.sender];
        uint256 debt = _getCurrentDebt(msg.sender);
        if (debt == 0) return;
        uint256 repayAmount = amount > debt ? debt : amount;
        bankToken.safeTransferFrom(msg.sender, address(this), repayAmount);
        uint256 remainingDebt = debt - repayAmount;
        if (remainingDebt == 0) {
            user.borrowAmount = 0;
            user.borrowIndex = 0;
        } else {
            user.borrowAmount = (remainingDebt * user.borrowIndex) / state.borrowIndex;
        }
        state.totalBorrows -= repayAmount;
        emit Repaid(msg.sender, repayAmount);
    }

    function liquidate(address user) external nonReentrant updateIndex {
        uint256 hf = _getHealthFactor(user);
        if (hf >= 1e18) revert LiquidationNotNeeded();
        UserPosition storage u = users[user];
        uint256 debt = _getCurrentDebt(user);
        // Liquidator can repay up to 50% of debt
        uint256 maxRepay = debt / 2;
        uint256 repayAmount = maxRepay;
        // Liquidator sends BCK
        bankToken.safeTransferFrom(msg.sender, address(this), repayAmount);
        // Bonus on collateral: repayAmount * (1 + bonus) / 1
        uint256 seizeAmount = (repayAmount * (PRECISION + liquidationBonus)) / PRECISION;
        if (seizeAmount > u.collateral) seizeAmount = u.collateral;
        u.collateral -= seizeAmount;
        state.totalCollateral -= seizeAmount;
        uint256 remainingDebt = debt - repayAmount;
        if (remainingDebt == 0) {
            u.borrowAmount = 0;
            u.borrowIndex = 0;
        } else {
            u.borrowAmount = (remainingDebt * u.borrowIndex) / state.borrowIndex;
        }
        state.totalBorrows -= repayAmount;
        bankToken.safeTransfer(msg.sender, seizeAmount);
        emit Liquidated(msg.sender, user, repayAmount, seizeAmount);
    }

    function getAccountInfo(address user) external view returns (
        uint256 collateral, uint256 debt, uint256 healthFactor, uint256 maxBorrow
    ) {
        collateral = users[user].collateral;
        debt = _getCurrentDebt(user);
        healthFactor = _getHealthFactor(user);
        if (collateral > 0) {
            maxBorrow = (collateral * liquidationThreshold) / PRECISION;
            if (maxBorrow > debt) maxBorrow -= debt;
            else maxBorrow = 0;
        }
    }

    function pause() external onlyOwner { _pause(); }
    function unpause() external onlyOwner { _unpause(); }
}
```

   - Repay reduces debt
   - Interest accrues over time (mine 100 blocks, check debt grows)
   - Liquidation triggers when HF < 1
   - Withdraw collateral while has borrow reverts

**Frontend (wagmi):**
- `useWriteContract` has built-in error handling
- Custom wrapper:
```typescript
async function safeContractWrite(config: UseWriteContractParameters) {
  try {
    const hash = await writeContractAsync(config);
    setPendingTx(hash);
    const receipt = await waitForTransactionReceipt({ hash });
    return receipt;
  } catch (err: any) {
    if (err?.cause?.data) {
      const reason = decodeRevertReason(err.cause.data);
      toast.error(reason);
    } else if (err?.message?.includes('User rejected')) {
      toast('Transaction cancelled');
    } else {
      toast.error(err?.shortMessage || err?.message || 'Transaction failed');
    }
    throw err;
  }
}
```

| Risk | Severity | Mitigation |
|------|----------|------------|
| Reentrancy in LendingPool | 🔴 Critical | OpenZeppelin `ReentrancyGuard` on all state-mutating functions |
| Oracle manipulation | 🔴 Critical | MVP uses fixed price (1 BCK = 1 USD). Production: Chainlink |
| Timelock bypass | 🟠 High | Proposer + Executor roles properly configured; admin renounces after setup |
| Frontend signing error | 🟡 Medium | Use wagmi's typesafe contract interaction; ethers v6 BigInt everywhere |
| DeepSeek hallucinates params | 🟡 Medium | System prompt constrains to 6 tools; frontend always confirms before tx |
| First depositor inflation | 🟢 Low | OpenZeppelin ERC4626 v5 mitigates with `_checkZeroAndConvert` |
| RPC rate limits (faucet) | 🟢 Low | Fallback to public RPC; local Hardhat node for dev |
